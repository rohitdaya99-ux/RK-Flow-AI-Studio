# Diagnostics Checklist

## Bridge
- Temp directory exists
- Read/write permissions work
- Bridge panel opens
- Bridge health file is created

## Premiere
- Premiere process is running
- Project opens
- Active sequence is readable

## Tools
- `project.open` works
- `sequence.getActive` works
- `timeline.insertClip` works
- `effects.applyVideoEffect` works
- `export.sequenceMediaEncoder` works
