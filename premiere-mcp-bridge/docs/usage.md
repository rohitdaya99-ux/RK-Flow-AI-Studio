# Usage

## Gemini flow
- Parse local-language prompt.
- Detect event.
- Build plan.
- Route to Premiere tools.
- Export final reel.

## Example prompts
- Haldi ki energetic reel banao.
- Is photo wale person ki saari clips ek bin me lao.
- Instagram reel jaisa cut timing chahiye.
- SFX automatic add karo.
- Reception ka glamorous edit banao.
