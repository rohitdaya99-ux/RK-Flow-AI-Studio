# Installation

## Requirements
- Node.js 18+
- Adobe Premiere Pro with bridge support
- MCP client

## Steps
1. Extract the project folder.
2. Match the bridge temp directory in both MCP config and Premiere panel.
3. Start the MCP server.
4. Open Premiere Pro.
5. Open the bridge panel.
6. Run diagnostics.
7. Test read tools.
8. Test edit tools.
9. Test export.
